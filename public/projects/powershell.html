Script PowerShell développé en stage pour une société BTP multi-filiales. Objectif : remplacer une méthode de sauvegarde manuelle par un outil avec interface graphique, compressant et chiffrant automatiquement les dossiers sélectionnés via 7-Zip en AES-256.

Contexte

Le besoin client

Une société du secteur BTP avec plusieurs filiales effectuait ses sauvegardes manuellement, sans chiffrement. Les documents sensibles (devis, contrats, plans) n'étaient pas sécurisés. Le besoin : un outil simple, utilisable par des non-techniciens, fiable et sécurisé.

Solution apportée

  • Interface graphique Windows native (pas de ligne de commande)
  • Sélection libre de plusieurs dossiers en une seule exécution
  • Chiffrement AES-256 systématique via 7-Zip
  • Destination unique et centralisée pour toutes les filiales
  • Gestion automatique des doublons et des erreurs

Fonctionnalités clés

📱

Interface graphique native

Aucune ligne de commande. L'utilisateur interagit uniquement via des boîtes de dialogue Windows standard, accessibles à tous les employés.

📁

Multi-dossiers

Après chaque sélection, le script propose d'en ajouter un autre. La boucle continue jusqu'à ce que l'utilisateur confirme la fin de sélection.

🔒

Chiffrement AES-256

Chaque archive est chiffrée avec AES-256 via 7-Zip. Sans le mot de passe, les fichiers sont inaccessibles même en cas de vol du support.

♻️

Gestion des doublons

Si une archive du même nom existe déjà à destination, elle est automatiquement écrasée. Pas d'accumulation de fichiers obsolètes.

🛠️

Création auto du dossier

Si le dossier de destination n'existe pas, il est créé automatiquement. Le script ne plante pas sur une cible manquante.

🚨

Gestion des erreurs

Chaque opération retourne un code de sortie 7-Zip. En cas d'échec, une boîte de dialogue alerte l'utilisateur avec le nom du dossier concerné.

Extrait du code

PowerShell 
# Boucle de sélection multi-dossiers
while ($dialog.ShowDialog() -eq "OK") {
    $selectedFolders += $dialog.SelectedPath
    $reselect = [System.Windows.Forms.MessageBox]::Show(
        "Voulez-vous selectionner un autre dossier ?",
        "Ajouter un autre dossier", "YesNo"
    )
    if ($reselect -eq "No") { break }
}

# Compression AES-256 via 7-Zip
foreach ($source in $selectedFolders) {
    $arguments = "a -tzip `"$zipPath`" `"$source\*`" -r -p$password -mem=AES256"

    $processInfo = New-Object System.Diagnostics.ProcessStartInfo
    $processInfo.FileName       = $sevenZipPath
    $processInfo.Arguments     = $arguments
    $processInfo.CreateNoWindow = $true   # exécution silencieuse

    $process = New-Object System.Diagnostics.Process
    $process.StartInfo = $processInfo
    $process.Start()     | Out-Null
    $process.WaitForExit()
}

Déroulement du stage

Étape 1

Analyse du besoin

Audit de la méthode de sauvegarde existante : copies manuelles sans chiffrement, risques de perte et d'accès non autorisé aux documents. Définition des exigences avec le responsable informatique.

Étape 2

Choix des technologies

PowerShell natif Windows pour éviter toute installation supplémentaire. 7-Zip pour la compression et le chiffrement AES-256. Interface graphique via System.Windows.Forms pour une prise en main immédiate.

Étape 3

Développement & tests

Développement itératif du script : boucle de sélection, gestion des cas d'erreur (dossier inexistant, doublon, échec 7-Zip), exécution silencieuse du processus. Tests sur différents profils utilisateurs.

Étape 4

Déploiement & remise

Livraison du script accompagné d'une documentation utilisateur. Déploiement sur les postes des différentes filiales. Prise en main validée par les employés sans formation technique.
